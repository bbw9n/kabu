# Kabu MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a polished macOS-only GPUI desktop market watcher with a persistent US-stock and crypto watchlist, search, live quotes, quote-detail charts, and three themes.

**Architecture:** A three-crate Cargo workspace keeps provider-neutral market models and policy in `kabu-core`, external I/O adapters in `kabu-data`, and GPUI state/rendering in `kabu-app`. A dedicated Tokio runtime thread owns HTTP and WebSocket tasks; typed commands and events cross into the GPUI executor through `async-channel`, so networking never blocks the UI thread.

**Tech Stack:** Rust 1.96, edition 2024, GPUI 0.2.2, gpui-component 0.5.1, Tokio 1.53, Reqwest 0.13, tokio-tungstenite 0.30, Serde, Chrono, async-channel, Wiremock.

**Spec:** `docs/superpowers/specs/2026-08-19-kabu-design.md`

## Global Constraints

- Target macOS only; v1 is one standalone window, not a menu-bar application.
- Use exactly three workspace crates: `kabu-core`, `kabu-data`, and `kabu-app`.
- Pin GPUI to `=0.2.2` and gpui-component to `=0.5.1`; commit `Cargo.lock`.
- Default window size is 980 by 640 points; minimum size is 760 by 500 points.
- The starter watchlist is AAPL, NVDA, BTC/USDT, and ETH/USDT.
- Search debounce is 250 milliseconds; Command-K opens search.
- Stocks poll every 15 seconds while visible; failure intervals are 30, 60, then 120 seconds with up to 20 percent jitter.
- Crypto streams while visible; reconnect intervals are 1, 2, 4, 8, 16, 32, then 60 seconds with up to 20 percent jitter.
- Chart cache TTLs are 60 seconds for 1D, 5 minutes for 1W/1M, and 30 minutes for 3M/1Y.
- Ship System, Graphite, Midnight, and Signal theme settings. System maps macOS light to Graphite and dark to Midnight.
- No trading, accounts, credentials, telemetry, position tracking, additional markets, or candlestick rendering.
- Default tests are hermetic and make no public-network requests; live Yahoo/Binance tests are ignored and opt-in.
- Preserve source and timestamp on every quote; never render missing data as zero.

- [ ] **Step 4: Implement exact policy contracts**

Implement `Freshness::{Live, Fresh, Aging, Delayed, Stale, Closed, Unavailable}`. Crypto is Live through 5 seconds and Stale after 15 seconds; between those values return Aging with the visible age. - [ ] **Step 3: Implement runtime ownership and visibility lifecycle**

The runtime thread constructs `YahooClient`, `BinanceClient`, and `JsonRepository`. pub trait VisibilityProbe: Send + Sync {

}
